GitHub Copilot DevDays bei der Deutschen Bank

14.10.2026 · 18:00 Deutsche Bank Berlin Technology Centre Eintritt frei

Am Mittwoch, dem 14. Oktober 2026, laden die Java User Group Berlin-Brandenburg, das Berlin Technology Centre der Deutschen Bank und JCON zu den GitHub Copilot DevDays ein. Von 18:00 bis 21:00 Uhr erwarten euch Live-Demos, praktische Übungen und gemeinsamer Austausch rund um die Softwareentwicklung mit KI.

Der Workshop-Abend

Entdeckt, wie ihr GitHub Copilot und KI-Agenten im Entwicklungsalltag einsetzen könnt. Die Einführung stellt zentrale Funktionen, praktische Beispiele und agentengestützte Arbeitsabläufe vor. Anschließend könnt ihr die Werkzeuge in kleinen Gruppen selbst ausprobieren und gemeinsam Software entwickeln.

Die Veranstaltung findet auf Deutsch und Englisch statt.

Die geplanten Workshops

  • Workshop zur GitHub Copilot App: Erkundet die agentengestützte Entwicklung vom Auswählen eines Issues über das Starten von Agenten bis zum Prüfen von Änderungen und Zusammenführen von Pull Requests.
  • Agent Lab - Java: Entwickelt eine Social-Bingo-Anwendung mit Java und Spring Boot und nutzt dabei den Agent Mode von GitHub Copilot in VS Code.
  • Anwendungsmodernisierung: Modernisiert eine bestehende Java-Anwendung mit GitHub Copilot. Dazu gehören das Upgrade von Java 8 auf Java 21, das Ergänzen von Health-Endpunkten und die Containerisierung der Anwendung.

Der Treffpunkt

◎ Deutsche Bank Berlin Technology Centre Otto-Suhr-Allee 16, 10585 Berlin

Der Ablauf

18:00 Einlass
18:30 Begrüßung und Einführung in GitHub Copilot
19:00 Praktische Workshops in kleinen Gruppen
20:00 Austausch bei Essen und Getränken
21:00 Ende der Veranstaltung

Die Vorbereitung

Bitte bringt euren Laptop mit. Ihr benötigt ein GitHub-Konto. Falls ihr keine GitHub-Copilot-Lizenz habt, haltet bitte ein persönliches GitHub-Konto für den Workshop-Zugang bereit.

Über das Berlin Technology Centre

Das Berlin Technology Centre (BTC) ist einer der wichtigsten globalen Technologiestandorte der Deutschen Bank. Im Herzen Berlins arbeiten hier Fachleute für Softwareentwicklung, Architektur, Daten und weitere Technologiebereiche an Software und Plattformen für das weltweite Geschäft der Bank.

Die Anmeldung

Meldet euch über die Meetup-Veranstaltung der JUG Berlin-Brandenburg an. Wir freuen uns auf euch!
