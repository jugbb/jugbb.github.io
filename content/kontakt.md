Die Aktivitäten der Java User Group Berlin-Brandenburg können über verschiedene soziale Kanäle verfolgt werden.
Neben unserem **Blog** sind ** Meetup und LinkedIn unsere Hauptplattformem** und jeder, der automatisch Einladungen zu unseren Veranstaltungen und Hinweise auf weitere interessante Veranstaltungen erhalten möchte, sollte am besten [Mitglied in unserer Meetup-Gruppe][meetup] werden.

Der beste Weg, um mit uns **direkt in Kontakt** zu treten ist per [E-Mail][mail].

## Die JUG in den sozialen Medien

- [LinkedIn-Seite der Java User Group Berlin-Brandenburg][li]
- [Meetup-Gruppe der Java User Group Berlin-Brandenburg][meetup]

## Direkter Kontakt zur JUG

Für eine direkte Kontaktaufnahme mit der JUG Berlin-Brandenburg bitte eine [E-Mail an Oliver B. Fischer][mail] senden.
