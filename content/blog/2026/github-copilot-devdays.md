Am **Mittwoch, dem 14. Oktober 2026**, laden die Java User Group Berlin-Brandenburg, das **Berlin Technology Centre der Deutschen Bank** und **JCON** zu den **GitHub Copilot DevDays** ein.
Von **18:00 bis 21:00 Uhr** erwarten euch Live-Demos, praktische Übungen und gemeinsamer Austausch rund um die Softwareentwicklung mit KI.

<!--more-->

## Der Workshop-Abend

Entdeckt, wie ihr GitHub Copilot und KI-Agenten im Entwicklungsalltag einsetzen könnt.
Die Einführung stellt zentrale Funktionen, praktische Beispiele und agentengestützte Arbeitsabläufe vor.
Anschließend könnt ihr die Werkzeuge in kleinen Gruppen selbst ausprobieren und gemeinsam Software entwickeln.

Die Veranstaltung findet auf **Deutsch und Englisch** statt.

## Die geplanten Workshops

- **Workshop zur GitHub Copilot App:** Erkundet die agentengestützte Entwicklung vom Auswählen eines Issues über das Starten von Agenten bis zum Prüfen von Änderungen und Zusammenführen von Pull Requests.
- **Agent Lab - Java:** Entwickelt eine Social-Bingo-Anwendung mit Java und Spring Boot und nutzt dabei den Agent Mode von GitHub Copilot in VS Code.
- **Anwendungsmodernisierung:** Modernisiert eine bestehende Java-Anwendung mit GitHub Copilot. Dazu gehören das Upgrade von Java 8 auf Java 21, das Ergänzen von Health-Endpunkten und die Containerisierung der Anwendung.

## Über das Berlin Technology Centre

Das Berlin Technology Centre (BTC) ist einer der wichtigsten globalen Technologiestandorte der Deutschen Bank.
Im Herzen Berlins arbeiten hier Fachleute für Softwareentwicklung, Architektur, Daten und weitere Technologiebereiche an Software und Plattformen für das weltweite Geschäft der Bank.
