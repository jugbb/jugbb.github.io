The Java User Group Berlin-Brandenburg and [JetBrains](https://www.jetbrains.com/) invite you to an evening with three talks on **Wednesday, July 9th, 2025** featured by WeAreDevelopers World Congress!

<!--more-->

## The Talks

**Kotlin Notebooks** (_Teodor Irkhin_)

Kotlin Notebooks are a lightweight and expressive tool for solving everyday developer tasks.
Teodor will show how they shine for tasks like CSV file processing, database access, and API exploration — things that used to require a full project setup but now fit in a notebook.

**Cloud Vendor Lock-In** (_Björn Stahl_)

Cloud vendor lock-in is often treated as something to be avoided at all costs.
Björn draws a comparison to historical database abstraction layers and explores both sides: when lock-in is a liability and when accepting it is a conscious, pragmatic decision.

**Architecture Communication Canvas** (_Gernot Starke & Benjamin Wolf_)

The Architecture Communication Canvas (ACC) is a one-page format for communicating software architecture to different stakeholders.
Gernot and Benjamin share two years of hands-on experience applying the ACC across different industries and team setups — what worked, what didn't, and where the framework continues to evolve.
