Spec Driven Development — Wie KI alles verändert und warum trotzdem nichts neu ist

09.06.2026 · 18:30 Capgemini Berlin Simon Martinelli Eintritt frei

Am Dienstag, den 9. Juni 2026, lädt die Java Usergroup Berlin-Brandenburg gemeinsam mit Capgemini zum Vortrag von Simon Martinelli ein.

Der Vortrag

Spec Driven Development: Wie KI alles verändert — und warum trotzdem nichts neu ist (Simon Martinelli): KI macht das Programmieren schneller denn je. Doch Geschwindigkeit war nie das eigentliche Problem.

In den meisten Projekten ist Code immer noch die maßgebliche Quelle. Anforderungen verändern sich, Dokumentationen veralten, und Entwickler verbringen mehr Zeit mit der Behebung von Missverständnissen als mit der Entwicklung von Lösungen. Schnelleres Tippen löst dieses Problem nicht.

Dieser Vortrag stellt einen anderen Ansatz vor: den AI Unified Process (AIUP) — https://aiup.dev.

Anstatt mit Code zu beginnen, starten wir mit klaren, strukturierten Anforderungen. Diese Anforderungen bilden das zentrale Artefakt. Aus ihnen generiert KI Diagramme, Modelle, Code und Tests. Ändern sich die Anforderungen, wird das System kontrolliert und konsistent aktualisiert.

KI gibt Softwareentwicklern die Möglichkeit, das zu tun, was sie schon immer hätten tun sollen: Systeme entwerfen, die Domäne verstehen und die richtige Lösung entwickeln. Nicht einfach nur mehr Code.

Sie erfahren, wie Sie Anforderungen formulieren, mit denen KI zuverlässig arbeiten kann, und wie Sie Geschäftsziele, Architektur und Implementierung im Laufe der Zeit synchron halten. Der Vortrag basiert auf realen Projekten und zeigt konkrete Arbeitsabläufe, keine Theorie.

Der Redner

SM

Simon Martinelli ist Java Champion, Vaadin Champion und Oracle ACE Pro mit über drei Jahrzehnten Erfahrung als Softwarearchitekt, Entwickler, Berater und Trainer. Er ist der Schöpfer des AI Unified Process (AIUP) und ein überzeugter Verfechter von Spec-Driven Development.

Als Inhaber der Martinelli LLC coacht er Teams beim Einstieg in KI-gestützte Entwicklung. Regelmäßig teilt er seine Erkenntnisse auf internationalen Konferenzen, in Artikeln und in seinem Blog „Keep IT Simple" (https://martinelli.ch), wo er über KI, Architektur und modernes Java schreibt.

Zudem ist er Dozent an zwei Schweizer Hochschulen und unterrichtet Softwarearchitektur, Persistenz, DevOps und Cloud-native Entwicklung.
